### Rules for using this list
1. One keyword = one page. Put the keyword in the H1, the first 60 words, the title tag and one H2.
2. Title format: `Primary Keyword — Secondary | Vametra AI` (≤60 chars).
3. Meta description: answer the query in ≤155 chars, include a number or date.
4. Every tool page needs a **worked example** with real figures and an as-of date — that's what AI engines quote.
5. Internal links: each corridor page links to the duty calculator, HS finder and its country profile.
